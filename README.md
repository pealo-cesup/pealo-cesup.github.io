# PEALO · CESUP

**P**ronta **E**quipe de **A**tendimento e **L**iberação de **O**corrências do CESUP/UFRGS.

> *Pealo* é o laço gaúcho lançado nas patas dianteiras do animal em disparada. A PEALO segura o incidente antes que ele se espalhe e devolve o serviço à normalidade.

Site estático (HTML + CSS, publicado pelo GitHub Pages) do **Sistema de Registro de Incidentes do datacenter**. A definição em vigor é a **v7.0** (C4 Model), sobre a versão final v6.1. As apresentações anteriores aparecem como trajetória:
